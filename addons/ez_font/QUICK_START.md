# ⚡ Ez Font - Quick Start

## 🎯 In 3 Minutes

### 1️⃣ Install Module
```
Apps → Search "Ez Font" → Install
```

### 2️⃣ Go to Settings
```
Settings → Administration → ตั้งค่าฟอนต์
```

### 3️⃣ Create & Apply Font

**Click Create:**
- ชื่อฟอนต์: `Prompt`
- Google Font URL: `https://fonts.googleapis.com/css2?family=Prompt`
- Click Save

**Click "ใช้งานฟอนต์นี้"** → ✅ Done!

---

## 🌐 Popular Google Fonts URLs

### Thai
- **Prompt**: `https://fonts.googleapis.com/css2?family=Prompt`
- **Kanit**: `https://fonts.googleapis.com/css2?family=Kanit`

### English
- **Roboto**: `https://fonts.googleapis.com/css2?family=Roboto`
- **IBM Plex Sans**: `https://fonts.googleapis.com/css2?family=IBM+Plex+Sans`

---

## 🔄 Change Font

Simply activate a different font - old one auto-deactivates.

## ❌ Deactivate Font

Click "ยกเลิกใช้งาน" on any active font.

---

## 💡 Tips

- **Hard Refresh**: Ctrl+Shift+R to see changes immediately
- **Only One Active**: System auto-switches when activating new font
- **No Restart**: Changes apply instantly
- **Any CSS Selector**: Use `.o_form_view`, `.o_list_view`, etc.
